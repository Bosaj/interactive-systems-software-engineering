# Getting Started & Setup Guide 🚀

Follow this comprehensive guide to set up your local development environment for **ENIAD Software Engineering & Interactive Systems (Semestre 6)**.

---

## 📋 Prerequisites

- **Node.js**: 18+ and `npm`
- **Expo CLI**: `npx expo`
- **C/C++ Compiler**: GCC / Clang
- **Git**: 2.30+

---

## 📥 Cloning & Running

```bash
git clone https://github.com/Bosaj/interactive-systems-software-engineering.git
cd interactive-systems-software-engineering
```

### Running React / Expo IHM Projects:
```bash
cd "Dveloppement d'IHM/TP/TP4/TP"
npm install
npx expo start
```
